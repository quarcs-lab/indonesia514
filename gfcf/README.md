# Gross Fixed Capital Formation (GFCF) / PMTB

This folder contains district-level data for **Gross Fixed Capital Formation (GFCF)**, also known in Indonesian as **PMTB (Pembentukan Modal Tetap Bruto)**.

## Indicator

- **Name:** Total Gross Fixed Capital Formation (GFCF)
- **Unit:** IDR Billion
- **Definition:** Total GFCF in constant prices, real 2010 base year.
- **Share Indicator:** Data share GFCF tersedia sebagai **(GFCF/GDRP) * 100**.

## Data Notes

- **Year 2024:** Preliminary estimate (*Angka sementara*)
- **Year 2025:** Very preliminary estimate (*Angka sangat sementara*)

## File

- `gfcf.csv`: Main GFCF/PMTB dataset.
