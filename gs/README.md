# Government Spending / Pengeluaran Pemerintah

This folder contains district-level data for **Government Spending**, also known in Indonesian as **Pengeluaran Konsumsi Pemerintah**.

## Indicator

- **Name:** Government Spending
- **Label:** Local/District Government Spending (Gov_Spend)
- **Unit:** IDR Billion
- **Definition:** Government final consumption expenditure in constant prices, real 2010 base year.
- **Description:** Total Local/District Gov Spending (IDR Billion, real 2010 base year).
- **Share Indicator:** Data share Government Spending tersedia sebagai **(Government Spending/GDRP) * 100**.

## Data Notes

- **Coverage:** District/city level (kabupaten/kota).

## File

- `gs.csv`: Main Government Spending dataset.
